# Knowledge sources

Le dépôt conserve les métadonnées, les résumés originaux, les concepts, les versions, les URLs officielles, les dates de vérification et les statuts. Il ne recopie pas intégralement les guidelines, lois, articles ou contenus propriétaires.

La hiérarchie est : texte officiel ou portail d’autorité, métadonnée de registre, résumé Clinical Navigator, interprétation pédagogique, revue humaine. Une URL HTTPS ne suffit pas à établir l’applicabilité. Les références du `ReferenceRegistry` sont revues périodiquement et les changements deviennent `NEEDS_REVIEW`.

Les sources externes peuvent être temporairement indisponibles. L’audit de liens ne casse pas le build pour une panne HTTP externe, mais l’état doit devenir `NEEDS_REVIEW`.
